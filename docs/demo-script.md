## 짧은 영상으로 줄일 때

아래 여섯 구간이면 핵심이 다 들어간다. 이으면 1분 38초쯤이다. 영상 길이 규정은 접수 안내에서 확인한다.

1. 출발 브리핑의 앞 두 문장 (00:00~00:09)
2. 세종대왕릉 이야기의 첫 두 문장 (00:29~00:39)
3. 아이의 "퀴즈 하자"와 첫 문제, 정답과 조명 (00:42~00:44, 01:06~01:20)
4. 치악산 이야기가 내비 안내에 멈췄다가 같은 문장부터 이어지는 부분 (02:10~02:31)
5. 정차 제안에서 경유지 추가까지 (02:42~02:55)
6. 정차 화면이 열리는 순간과 도착 기록 (03:14~03:24, 06:06~06:25)
